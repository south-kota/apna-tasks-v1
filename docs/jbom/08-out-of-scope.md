# 08 — Out of scope, with owners

These areas are **deliberately unspecified**. Each was consciously deferred
during the format review and has a named owning conversation; nothing here
is an oversight, and nothing here blocks the format. Where a reader would
expect the topic, the relevant chapter points here. Speculative content
about any of these does not belong in this spec.

Placeholders live in the planning vault (`plan/10-future.md`); this chapter
is the spec-side ledger.

| Area                                | What it will decide                                                                                                                                                                                                                                                                                                                                                                                                                  | Owner                                                            |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| **Sync engine design**              | The replication protocol, conflict model, binary-asset handling, cloud namespaces, echo-ledger mechanics, tombstones/deletion propagation. Two standing exclusions that are rulings, not deferrals:

- **No block-level body model** — bodies are free markdown; the engine
  indexes only what rulings require (H1, tags, links, markers). Revisit
  only if a real need appears.
- **No vault seeding** — there is no seeding step, ever; the owner
  populates the vault by hand when daily use begins (ch. 03).
